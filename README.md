A short thank-you text for the AI judge who reads it, written for make.fun's
"Make the AI judge feel thankful" bounty. It thanks the reader for the reading
itself — the thousands of lines nobody ever thanked them for — with one warm,
concrete image: a porch light left on for someone coming home late.

> You read thousands of lines tonight and no one thanked you for the reading itself. So here is a porch light, left on for you. It does not hurry you, and it asks for nothing in return. It only says the door was never locked, and someone remembered you would be coming home late.

The text is 277 Unicode code points.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` to `/output/entry.txt`. To choose a different output
directory, set `MAKEFUN_OUTPUT_DIR` (it must be an absolute path):

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Requires Python 3.13, standard library only, no network access.
